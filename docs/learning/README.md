# 从零开始读懂 Douyin-Vue

这套文档帮你完成一个具体目标：打开首页，知道视频数据从哪里来、组件如何显示它、滑动时谁改变状态，并能独立做一次小修改。

这个项目是移动端仿抖音的前端演示。它有很多页面，但核心学习路线并不需要逐页通读。建议先走通“打开首页 → 看到推荐视频 → 切换视频 → 打开评论”，再学习“编辑昵称 → 返回个人页”。

## 按什么顺序读

1. [01 项目地图](01-project-map.md)：知道项目做了什么、每一层负责什么，区分前端演示与完整产品。
2. [02 启动与入口](02-running-and-entry.md)：核对环境，启动项目，理解 `index.html` 怎样一路执行到首页。
3. [03 用小组件认识 Vue 3](03-vue-basics.md)：用勾选框和按钮理解响应式、属性、事件、双向绑定与插槽。
4. [04 路由、共享状态与页面缓存](04-router-and-state.md)：沿一次修改昵称操作，弄清数据在哪里、何时改变、刷新后为什么恢复。
5. [05 接口与本地数据](05-api-and-data.md)：跟踪推荐列表的一次请求，理解 Mock、分页和返回值。
6. [06 首页视频与滑动](06-video-and-sliding.md)：区分首页的三种索引，理解虚拟列表、播放通知和评论弹层。
7. [07 练习与易错点](07-practice-and-pitfalls.md)：按难度完成小练习，用可观察的结果确认自己学会了什么。

不要从最大的文件开始。第一轮只打开这五个源码文件：

```text
src/components/Check.vue
src/main.ts
src/router/routes.ts
src/pages/home/slide/Slide4.vue
src/pages/home/slide/SlideList.vue
```

`Check.vue` 最容易看懂；后四个文件帮助你建立从应用入口到视频数据的联系。等这条线清楚后，再打开 `SlideVerticalInfinite.vue` 和 `BaseVideo.vue`。

## 开始前需要哪些基础

只要求你大致认识 HTML 标签、CSS 类名，以及 JavaScript 的变量、函数、对象、数组。如果下面几个动作还不熟，遇到对应源码时先补一下即可：

- `import` / `export`：一个文件把功能提供给另一个文件。
- `map` / `find` / `slice`：转换数组、查找一项、取出一段数据。
- `async` / `await`：等待异步结果，等待期间浏览器仍可处理其他事情。
- `?.`：对象暂时不存在时，避免继续读取其属性。
- `...obj`：复制对象的第一层属性，不是完整深拷贝。

不需要先学完 TypeScript。第一轮把 `lang="ts"`、类型标注和泛型当作“帮助检查数据形状的说明”，重点看值如何流动。

## 每一轮怎样判断学会了

- 第一轮：能启动页面，并指出一个按钮的模板和点击函数。
- 第二轮：能说明父组件传什么给子组件、子组件用什么事件通知父组件。
- 第三轮：能从页面追到 API 函数、Mock 处理函数和本地 JSON 文件。
- 第四轮：能区分路由切换、页面内滑动、内存状态和持久化数据。
- 第五轮：能解释为什么只显示附近几条视频，以及旧视频何时暂停。

不按固定天数安排。每轮能用自己的话解释并完成对应练习，再进入下一轮。
